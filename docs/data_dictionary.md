# 字段与口径字典

> 本文件记录**已核实**的字段口径。标注「待核实」的条目禁止直接用于业务结论。

**数据时间范围**：行为/评论 2018-02-01 ~ 2018-04-15（74 天）；用户注册 2003-06-13 ~ 2018-04-15

---

## jdata_user.csv（1,048,575 行）

| 字段 | 类型 | 取值 | 口径 |
|---|---|---|---|---|
| `user_id` | int | 唯一，无重复 | 用户唯一标识 |
| `age` | float | **1~6** |  **年龄段编码，非实际年龄**（均值 4.6 不可能是岁数）。| 
| `sex` | float | 0 / 1 / **-1** | 0=女? 1=男? **-1 为缺失占位**（7,700 条，0.73%），须转 NaN |
| `user_reg_tm` | str | 2003-06-13 ~ 2018-04-15 | 用户注册日期，格式 `YYYY-M-D` 不统一 |
| `user_lv_cd` | int | 1~7 | 用户等级编码，越大等级越高（1=31.7万，2=仅8条，3=6千，4=4千，5=22.8万，6=28.8万，7=20.6万）。**2 级样本过小** | 
| `city_level` | float | 1~6 | 城市等级编码，**1=一线**（1 有 21.99 万，2 仅 1.59 万，符合一线城市稀缺特征） | 
| `province` | float | 1~31 |  **省份编码，非名称**。共 31 个（对应省级行政区） |
| `city` | float | 整数 |  **城市编码** | 
| `county` | float | 整数 |  **区县编码** |

**缺失**：age 1,661（0.16%）、sex 671（0.06%）、city_level 1,061（0.10%）、province/city/county 各 1,039（0.10%）

## jdata_comment.csv（1,774,233 行，主键 = dt + sku_id）

| 字段 | 类型 | 取值 | 口径 | 
|---|---|---|---|---|
| `dt` | str | 2018-02-01 ~ 2018-04-15 | 统计日期 | 
| `sku_id` | int | 160,137 个唯一值 | 其中 5,913（3.69%）在 product 表中缺失 | 
| `comments` | int | 1 ~ 1,541，无 0 无负 | 当日评论总数 | 
| `good_comments` | int | 0 ~ 1,541 | 当日好评数 | 
| `bad_comments` | int | 0 ~ 416 | 当日差评数 |

**勾稽关系**：`good + bad ≤ comments` 恒成立 ✅；差额为**中评**（合计 92,445 条，1.08%）。
**汇总指标**：总评论 8,537,575 条，好评率 **97.88%**，差评率 **1.04%**。
**零值情况**：`good_comments = 0` 有 28,402 行；`bad_comments = 0` 有 1,699,059 行（95.8%，差评稀疏属正常）。

## 全局约束

- **无金额字段**：全数据集不含价格/金额，**GMV、客单价、ARPU 均不可计算**，交易分析只能用行为量级指标（下单次数、转化率、复购率）。
- **用户样本收缩**：跨表分析（行为+画像）的可用用户约 104.9 万，而非 160.9 万，须在报告中声明口径。
